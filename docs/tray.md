# 系统托盘

Rusker Desktop 启动时会创建系统托盘图标。若当前桌面不支持托盘，主窗口和所有容器功能仍可使用，设置页会显示初始化警告。

## 菜单

- **显示主窗口**：恢复并激活主窗口。
- **最小化到托盘**：最小化窗口，保留页面状态和后台任务。
- **刷新容器状态**：恢复窗口并执行与页面刷新按钮相同的操作。
- **打开容器 / 打开镜像 / 打开设置**：恢复窗口并切换到对应页面。
- **退出 Rusker**：真正退出应用，不只是最小化。

左键点击托盘图标恢复主窗口；右键或平台默认操作打开菜单。

## 关闭与退出

托盘可用时，主窗口关闭按钮会转换为“最小化到托盘”，不会销毁 `RuskerApp`、输入状态或正在等待的 Engine 操作。需要结束进程时，请使用托盘菜单“退出 Rusker”。

## 平台说明

- Windows：原生托盘图标与菜单。
- macOS：主线程原生状态栏图标与菜单。
- Linux：使用 `ksni` / StatusNotifierItem D-Bus 协议，不需要 GTK 或 AppIndicator 开发库。桌面环境需要提供兼容的系统托盘；某些桌面默认隐藏或不支持第三方托盘图标。

Linux 无桌面会话或 D-Bus 不可用时不应强制启动托盘；应用会降级为普通窗口模式。
