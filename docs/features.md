# 功能列表与迭代范围

## 产品原则

1. 常用容器操作应有清晰、可恢复的反馈，不以静态演示数据代替真实引擎。
2. 默认不强制登录、不收集遥测、不设置商业版功能锁。
3. 删除等破坏性操作必须确认；默认不级联删除卷或其他资源。
4. UI 与引擎实现解耦，优先支持本地 Docker API，再逐步扩展其他后端。
5. Windows 与 Linux 是一等平台，macOS 代码路径不得被无必要地排除。

## 首版：本地容器与镜像管理

### 引擎与概览

- [x] 自动连接本机 Docker/Podman 兼容 API，并遵循 `DOCKER_HOST`
- [x] Windows 受管 WSL2 Engine：专用发行版、named pipe 代理、`/mnt/wsl` 共享 socket，不开放 TCP
- [x] `docker.exe` 绑定挂载可直接使用 Windows 路径（`C:\src` 自动转换为 `/mnt/c/src`）
- [x] 展示连接状态、Engine 版本、API 版本、操作系统和架构
- [x] 展示容器总数、运行数、停止数和镜像数
- [x] 手动刷新；连接失败时显示可读错误并允许重试

### 容器

- [x] 列出全部容器，包括已停止容器
- [x] Docker Desktop 风格列表：CPU/内存概要、搜索、仅显示运行中的容器、勾选批量删除
- [x] 按 Compose 项目标签分组，支持展开/折叠、整组选择及项目名搜索；普通容器独立显示
- [x] Compose 项目详情：工作目录与配置文件路径、服务列表、带服务名前缀的最近日志，以及项目级启动、停止和删除
- [x] 容器详情页：面包屑、状态与操作按钮、日志/详情/挂载/命令行/文件/统计 标签，复制 ID、镜像引用和日志
- [x] 命令行：持久 `/bin/sh -i` TTY 会话，点击终端直接输入，支持回车、退格、方向键、Tab、Ctrl+C、中文 IME 和粘贴；VT 终端仿真、窗口尺寸同步、滚动历史、复制当前屏幕、清屏和重新连接
- [x] 文件：只读浏览运行中容器的目录、返回上级、刷新，展示大小/修改时间/权限；依赖容器内的 sh、find、stat，不自动安装工具
- [x] 统计：CPU、内存、累计磁盘读写和网络收发四组实时趋势图，显示当前数值和 PID；保留最近 10 分钟、最多 300 个真实采样点，可切换采样数据表；采样完成后间隔 2 秒刷新，仅在此标签可见时轮询，错误自动重试，未采样区间断开
- [x] 展示名称、短 ID、镜像、状态、端口和创建时间
- [x] 按名称、ID、镜像和状态过滤
- [x] 查看选中容器的详情
- [x] 获取最近 200 行 stdout/stderr 日志
- [x] 启动、停止、重启容器
- [x] 通过本地镜像创建并运行容器，支持名称、CMD、TCP 端口映射、路径/卷挂载（可直接选 Windows 文件夹）和环境变量；从镜像列表运行时镜像固定显示
- [x] 删除前二次确认，不默认删除关联卷
- [x] 操作期间防止重复提交并展示结果

### 镜像

- [x] 展示镜像标签、短 ID、大小和创建时间
- [x] Docker Desktop 风格列表：每个标签一行（名称 / 标签分列），标出被容器使用的镜像，展示占用空间与上次刷新时间
- [x] 按名称、标签、创建时间、大小排序；按“使用中 / 未使用 / 悬空”筛选
- [x] 行内运行（预填镜像的创建容器对话框）、拉取最新版本、查看使用的容器、复制 ID / 引用
- [x] 点击镜像名称或容器的镜像链接进入详情：真实构建历史（含零大小元数据层）、展开命令并复制、平台 / 标签 / 摘要信息、运行和带确认的删除
- [ ] 漏洞扫描与软件包清单（SBOM）；详情页目前明确展示未接入分析的状态，不上传镜像或生成模拟结果
- [x] 勾选多个镜像批量删除；一键清理未被任何容器使用的镜像
- [x] 按标签、名称和 ID 过滤
- [x] 输入标准镜像引用并拉取
- [x] 消费拉取响应流，检测流内错误并显示阶段与最终结果
- [x] 删除前二次确认；不强制删除仍被使用的镜像；多标签镜像删除某行时只移除该标签

### 卷（Volumes）

- [x] 列出全部卷，展示使用状态、创建时间和大小（大小需 Engine API ≥ 1.52）
- [x] 按名称和驱动过滤
- [x] 创建卷（可留空由 Engine 命名），重名时拒绝而不是复用已有卷
- [x] 克隆卷：新建卷并完整复制数据（保留属主、权限、时间戳），失败时删除未完成的新卷
- [x] 删除前二次确认；不强制删除仍被容器引用的卷
- [x] 勾选多个卷批量删除；逐个删除并汇总失败项，不因单个失败中断
- [x] 一键清理未被任何容器（含已停止容器）挂载的卷，确认框列出将删除的卷
- [x] 卷详情：驱动、挂载点、标签和使用中的容器（可跳转到容器）
- [x] 浏览卷内容：逐级展开目录，展示大小、修改时间和权限（只读挂载）
- [x] 从本地 tar / tar.gz / tar.bz2 / tar.xz 归档导入数据，保留归档内属主与权限
- [x] 清空卷内全部文件并保留卷本身，操作前确认并提示运行中的容器
- [x] 导出卷到本地 tar 文件（可再次导入恢复），写完整后才替换目标文件；“导出”标签页列出本次运行的导出记录并可在文件夹中定位

卷内容的浏览、克隆和清空通过带 `dev.rusker.helper` 标签、无网络的临时 `busybox:1.37` 容器完成；本地缺少该镜像时会自动拉取一次，容器用完即删除。

### 通用体验

- [x] 加载、空列表、无搜索结果、操作中和失败状态
- [x] 后台 I/O 不阻塞 GPUI 主线程
- [x] 新请求取代旧请求，避免过期结果覆盖新状态
- [x] 中文界面和文档

### 设置

- [x] 跟随系统、浅色和深色主题，并持久化设置
- [x] 编辑 Docker Engine `HTTP_PROXY`、`HTTPS_PROXY`、`NO_PROXY`
- [x] 导出 `daemon.json` 的 `proxies` 片段；不自动改写系统配置或重启 Engine

### 系统托盘

- [x] 跨平台托盘图标和操作菜单
- [x] 恢复/最小化窗口、刷新、容器/镜像/设置导航和退出
- [x] 托盘可用时关闭按钮最小化，保留页面状态与后台任务

## 明确不做

- 不以 Rusker 名义重新分发来源不明的 Engine 二进制
- 不默认开启无认证、无 TLS 的远程 Docker API
- 不将商业使用限制加入项目许可证
- 不在用户不知情时上传日志、镜像名称或遥测数据
