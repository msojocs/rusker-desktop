Rusker Desktop 是一个使用 **Rust + [GPUI Kit](https://gpui-kit.com/)** 构建的开源容器桌面管理器。项目目标是提供类似 Docker Desktop 的常用管理体验，同时采用允许商业使用的 Apache-2.0 许可证。
